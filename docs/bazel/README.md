## Updating the reference

From the repository root, generate all pages with:

```sh
bazel run //docs/bazel:update
```

Commit the generated pages with the docstring changes. Check that they match
with:

```sh
bazel test //docs/bazel/...
```

The same diff tests run in repository CI through `bazel test //...`. The
committed Markdown is served by the existing Docsify site when changes land
on main, without a separate documentation deployment.

To document another module, add a `bzl_library` target beside its source, a
`macro_docs` target in this directory's `BUILD.bazel`, and its update target
in `update_docs`. Add links here and in `docs/_sidebar.md`. Use `symbol_names`
when a module imports public symbols that are documented elsewhere.
