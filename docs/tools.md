# Development tools

The repository's Bazel-managed development environment makes tools available
on `PATH` through direnv. These include `aspect`, `buildozer`, `ibazel`,
`java`, `jar`, `playwright`, and `pnpm`.

[`tools/BUILD.bazel`](../tools/BUILD.bazel) is the source of truth for the
tools that this repository adds to `PATH`. The environment is generated by
[bazel_env.bzl](https://github.com/buildbuddy-io/bazel_env.bzl).
