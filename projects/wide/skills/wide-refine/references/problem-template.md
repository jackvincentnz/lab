# Problem refinement guide

Describe a need that remains meaningful across candidate approaches and team boundaries. Use this guide
to find consequential gaps; unknowns are acceptable. Keep current understanding concise and reference
supporting material without repeating it in every field.

| Field           | Useful content                                                                                                                                                               |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Title           | A concise description of the need.                                                                                                                                           |
| Description     | Who experiences what difficulty and under which conditions. Include relevant attributed context and references.                                                              |
| Impact          | Magnitude, frequency, affected scope, and confidence where known. Separate active effort from elapsed delay; give the sample, denominator, and time window behind estimates. |
| Desired outcome | What improvement would mean, without prescribing an approach. Distinguish proposed targets from agreed ones.                                                                 |
| Questions       | Individual uncertainties whose answers could change a decision, with answers and sources when available.                                                                     |
| Decisions       | Human choices, reasons, and stated conditions for reconsidering. Agent proposals remain labeled reasoning.                                                                   |
| Links           | Why each signal is relevant, including limitations or contradictions; how candidate solutions could contribute.                                                              |

Distinguish observed facts, user judgments, and hypotheses where it matters. Limited code inspection or
one reported incident supports a bounded claim. Update conclusions when evidence changes, preserving
source attribution. Identify the next refinement need and why it matters in the relevant content.
