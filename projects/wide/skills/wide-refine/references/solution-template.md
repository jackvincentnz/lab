# Candidate solution refinement guide

A candidate is an option, not a delivery commitment. Keep the current proposal concise; include
supporting context and Markdown references where relevant. Use this guide to find the next important gap.

| Field         | Useful content                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Title         | A concise name for the approach.                                                                                         |
| Approach      | How it could produce an outcome. Distinguish the user's proposal from agent additions; qualify reports of existing work. |
| Scope         | Included behavior, exclusions, and acceptance conditions. Label unagreed scope and targets as proposed.                  |
| Tradeoffs     | Alternatives, risks, dependencies, reversibility, and whether related candidates compete or complement.                  |
| Effort        | Estimate or range with basis and uncertainty, if known.                                                                  |
| Questions     | Individual consequential uncertainties, retained answers, and supporting sources.                                        |
| Decisions     | Human choices and their reasons; only stated reconsideration conditions.                                                 |
| Problem links | Expected contribution to each need, mechanism, partial coverage, and what remains unresolved.                            |
| Signal links  | Why each observation matters; a proposal is not evidence that its approach works.                                        |

Before recommending a delivery decision, assess the linked need and outcome, bounded scope, acceptance
conditions, alternatives, effort assumptions, and material risks. Explain which uncertainty remains and
whether it is acceptable for that decision. Save the assessment in the relevant content. Filled fields
or an empty question list do not establish readiness. Keep adjacent work outside scope unless agreed.
